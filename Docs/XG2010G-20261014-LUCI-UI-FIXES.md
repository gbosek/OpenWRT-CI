# 下一版 LuCI 修复（2026-10-14）

MWAN4 停止/启动/重启后立即读取后端状态，只有真实服务状态符合请求才提示成功；后端拒绝、执行失败或无确认均提示错误。服务停止时概览显示“已停止”，保留已保存的WAN配置，旧轮询不能覆盖新状态。沿用原MWAN4后端配套，未统一R5/R7分支。

PON概览卡片铺满内容区域，显示名改为PON，采样设备名保持原样。只更新已有luci-app-pon-status卡片；naoki不超频版继续使用指定的OpenWrt_ONU_CONFIG，不重新加入旧PON插件。

验证：两套LuCI各7项实际浏览器控制测试；main原有13项概览测试和ACL/i18n检查；PON1440/390像素宽度测试。上述浏览器测试使用模拟RPC，并不证明路由器上的实际服务已停止。PPE/MWAN4/CPU/NPU配置保持不变。

修复在下一次构建时生效；已发布的超频和不超频固件没有这些新改动。本次提交不自动重跑固件。
